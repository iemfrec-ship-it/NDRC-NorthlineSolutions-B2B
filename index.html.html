Protection des données personnelles

Cette application est un outil pédagogique développé pour un usage en classe.

Aucune donnée n'est transmise à un serveur externe : toutes les informations (identifiant, réponses, score) restent uniquement dans la mémoire locale de votre appareil (stockage local du navigateur).
Aucun cookie tiers, aucun traceur publicitaire, aucun appel à une API externe n'est utilisé.
La seule donnée saisie est votre identifiant au format XX-YY (deux lettres du prénom, deux lettres du nom), utilisé uniquement pour retrouver votre progression, ainsi que vos réponses aux exercices.
Votre progression sur les 3 niveaux (Junior, Confirmé, Expert) est sauvegardée localement sur l'appareil utilisé, ce qui vous permet de reprendre où vous en étiez ou de changer de niveau à tout moment sans perdre vos données.
Le PDF généré est créé localement dans votre navigateur, disponible à tout moment via le bouton flottant ; il n'est envoyé à personne automatiquement. C'est à vous de le transmettre à votre professeur.

Scoring

Each level is self-contained (score does not carry over between levels). Automated exercises (vocabulary, comprehension) score +1 per correct answer, 0 otherwise. Oral exercises (6 and 7) are scored by the teacher out of 10. A level is validated when the student reaches at least 70% of the total possible points for that level.
